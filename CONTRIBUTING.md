# Contributing

Use focused pull requests. Run `make`, `./overfit --help`, `shellcheck install.sh`, `bash -n install.sh`, `gitleaks detect --source . --no-banner`, and `semgrep --config auto --error .` when those tools are available.

Do not include API keys, generated local configuration, private repository data, or destructive Git operations in examples. Explain any change to subprocess arguments, credential storage, or network requests.
